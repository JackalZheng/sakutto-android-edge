GPU harness (debug tool)

Runs one fixed English paragraph through the CPU backend and several WebGPU configurations of the on-device model, then compares the outputs. Used to diagnose garbled WebGPU output on Android. This page is not part of the translation product.

"Run harness" runs every config on this page, one after another. Op diagnostics (WebGPU vs CPU, per op)

Runs llama.cpp test-backend-ops with the shapes and types PLaMo 3 Translate 0.8B uses, on WebGPU and on the CPU reference, and reports NMSE, max abs error and NaN/Inf counts per case. Each op group runs in its own worker and WebGPU device. Does not need the model.
