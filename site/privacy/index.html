繁體中文

這是非官方移植版。Sakutto for Android Edge 是把開源擴充功能 Sakutto（作者 jammaru，MIT 授權）移植到 Android 版 Microsoft Edge 的非官方版本，由 JackalZheng/sakutto-android-edge 維護。本版本與原作者 jammaru 沒有關係，也不是 Preferred Networks, Inc. 的產品，與該公司無任何關聯。翻譯模型為 PLaMo 3 Translate，依 PLaMo Community License 使用（Built with PLaMo）。

重點

  • 翻譯在你的裝置上進行，網頁內容不會傳送到任何翻譯伺服器。
  • 沒有帳號、沒有廣告、沒有分析或遙測，也沒有當機回報。
  • 維護者（以及原作者）不會收到你翻譯的網頁、選取的文字、詞彙表或譯文。
  • 擴充功能唯一主動下載的檔案，是從 Hugging Face 取得的 PLaMo 模型。

擴充功能會讀取什麼

當你要求翻譯頁面、選取的文字，或在擴充功能的文字輸入頁輸入的內容，或在你開啟自動翻譯的網站上，擴充功能會讀取要翻譯的文字和你設定的選項。這些文字只用來在你的裝置上產生譯文。

不收集的資料

不收集、不上傳、不販售任何個人資料，也不用來建立使用者輪廓或投放廣告。

模型下載與誰看得到

PLaMo 3 Translate 模型沒有包含在擴充功能套件裡。第一次需要時，擴充功能會從 Hugging Face 官方儲存庫下載模型並保存在裝置上。在 Android 版 Edge 上只提供 0.8B 模型（約 573 MB）。Hugging Face 和傳送檔案的網路可以看到你的 IP 位址以及模型檔被請求這件事，但看不到網頁內容、選取文字、詞彙表或譯文。下載完成後，翻譯不需要網路。Edge 本身可能會更新擴充功能，那是瀏覽器的連線，不是本擴充功能發出的。

Edge 上的差異

Edge 沒有 Chrome 內建的 Translator API，因此本版本只使用 PLaMo，不會把文字交給其他翻譯引擎。

保存在裝置上的資料

設定（目標語言、文體等）、詞彙表與各網站規則、同意授權的紀錄、模型檔，以及本機翻譯快取。這些都只存在你的裝置上。你可以在設定中刪除模型並清除快取；移除擴充功能會一併移除其餘資料。

權限

安裝時不會取得所有網站的存取權。單次翻譯目前分頁使用瀏覽器針對該動作授予的權限（activeTab）。特定網站的存取權是選用的，只有在你為該網站開啟自動翻譯時才會要求。

聯絡方式

對本政策或本移植版有疑問，請到 https://github.com/JackalZheng/sakutto-android-edge/issues 開 issue。請不要把本移植版的問題回報給原作者。

English

This is an unofficial port. Sakutto for Android Edge is an unofficial port of the open-source extension Sakutto (by jammaru, MIT License) to Microsoft Edge for Android, maintained at JackalZheng/sakutto-android-edge. It is not affiliated with or endorsed by jammaru, and it is not a product of, nor affiliated with, Preferred Networks, Inc. The translation model is PLaMo 3 Translate, used under the PLaMo Community License (Built with PLaMo).

At a glance

  • Translation runs on your device. Page text is not sent to any translation server.
  • No account, no advertising, no analytics, telemetry or crash reporting.
  • The maintainer (and the upstream author) never receive the pages you translate, your selections, your glossary or the translations.
  • The only file the extension downloads is the PLaMo model, from Hugging Face.

What the extension reads

When you ask it to translate a page, a selection, or text typed on its own typed-text page, or when a site is set to translate automatically, the extension reads the text it is about to translate and the settings you entered. That text is used only to produce a translation on your device.

What is not collected

No personal data is collected, uploaded or sold, and nothing is used for profiling or advertising.

The model download, and who can see it

The PLaMo 3 Translate model is not bundled. The first time it is needed, the extension downloads it from the official Hugging Face repository and keeps it on your device. On Edge for Android only the 0.8B model (about 573 MB) is offered. Hugging Face and the network serving the file can see your IP address and that a model file was requested; they do not receive page text, selections, your glossary or translations. After the download, translation works offline. Edge may update the extension itself; that is the browser's request, not one this extension makes.

Differences on Edge

Edge has no Chrome built-in Translator API, so this port uses PLaMo only and never hands text to another engine.

Stored on your device

Your settings, glossary and per-site rules, a record that you accepted the license, the model file, and a local translation cache. You can delete the model and clear the cache in the settings; removing the extension removes the rest.

Permissions

The extension does not get access to every site at install. A one-time translation of the current tab uses the access the browser grants for that action (activeTab). Access to a particular site is optional and requested only when you turn on automatic translation for it.

Contact

Open an issue at https://github.com/JackalZheng/sakutto-android-edge/issues. Please do not report problems with this port to the upstream author.

日本語

これは非公式の移植版です。Sakutto for Android Edge は、オープンソースの拡張機能 Sakutto（作者 jammaru、MIT License）を Android 版 Microsoft Edge に移植した非公式版で、JackalZheng/sakutto-android-edge で管理しています。原作者 jammaru とは関係がなく、Preferred Networks, Inc. の製品でもなく、同社とも関係ありません。翻訳モデルは PLaMo 3 Translate で、PLaMo Community License に従って使用しています（Built with PLaMo）。

要点

  • 翻訳は端末の中で行い、ページの本文を翻訳サーバーへ送りません。
  • アカウント、広告、分析、テレメトリ、クラッシュ報告はありません。
  • 管理者（および原作者）は、翻訳したページ、選択範囲、用語集、訳文を受け取りません。
  • 拡張機能が取得するファイルは、Hugging Face から取る PLaMo のモデルだけです。

モデルのダウンロード

モデルは同梱していません。最初に必要になったとき Hugging Face の公式リポジトリから取得し、端末に保存します。Android 版 Edge では 0.8B モデル（約 573 MB）だけを提供します。Hugging Face とファイルを配信するネットワークには IP アドレスとモデルが要求されたことが伝わりますが、本文、選択範囲、用語集、訳文は伝わりません。取得後の翻訳に通信は要りません。

Edge での違い

Edge には Chrome 内蔵の Translator API がないため、PLaMo だけを使います。

端末に保存するもの

設定、用語集とサイトごとの規則、ライセンスへの同意の記録、モデルのファイル、翻訳キャッシュ。設定画面でモデルの削除とキャッシュの消去ができ、拡張機能を削除すると残りも消えます。

権限

インストール時にすべてのサイトへのアクセスは得ません。現在のタブの一回だけの翻訳には、その操作に対してブラウザが与えるアクセス（activeTab）を使います。特定サイトへのアクセスは任意で、そのサイトの自動翻訳をオンにしたときだけ要求します。
